- 这里存放界面设计的参考稿（用户提供的截图 / 设计图），后续界面改动的视觉基准以此为准。
- 命名约定：`ui-<窗口或场景>.png`，例如 `ui-main.png`、`ui-editor.png`。
- 新增参考时在 AGENTS.md 的 §11「界面设计与视觉基线」登记文件名，并把关键约定（配色、圆角、间距、控件形态）用文字补在下方，便于无法查看图片的会话也能照着实现。
- 目前还没有用户提供的设计稿图片。用户指定的**效果参考**是 [liquid-glass-studio](https://github.com/iyinchao/liquid-glass-studio)（在线演示 https://liquid-glass.iyinchao.cn/，MIT）：
  液态玻璃的折射、色散、菲涅尔反射、高光、模糊、色调、阴影与超椭圆圆角，以及「高级设置」里各参数的名字、范围与默认值都以它为准（见下方「液态玻璃参数」）。
- 「批量修改标签」窗口的**布局参考**是用户在对话里给的一张标签编辑器（Mp3tag）截图（2026-11-10；截图里有用户自己的文件名与目录，没有放进仓库）。文字要点：
  - 左右两栏：**右边是歌曲列表**，列依次是文件名、目录、标签格式、标题、艺术家、专辑、专辑艺术家、年份、音轨号、碟号、风格、作曲家、作词家；选中的行整行高亮。
  - **选中歌曲后左边显示它的标签**，一项一行、标签名在输入框上方：标题、艺术家、专辑、年份、音轨号 + 碟号（并排）、风格、专辑艺术家、作曲家、作词家、注释、歌词（只显示一行，旁边有打开编辑的按钮），最下面是封面缩略图，右侧列出格式、像素尺寸、大小、图片类型。
  - 只取它的布局与字段次序，观感仍是本项目的液态玻璃；截图里每个字段旁的工具按钮与封面下的「覆盖」勾选框不做。与截图不同的两处：年份与音轨号、碟号排在同一行（省一行，1280×800 的默认窗口里整个面板连封面都不用滚动）；列表多一栏「状态」，放在文件名后面。用户确认过的做法：左边可编辑、多选时只把改过的字段写进所有选中的歌（值不同的字段显示「〈保持〉」）；歌词只预览一行、用歌词与标签编辑器编辑；在线获取保留，作用于选中的歌。

## 关键约定（当前实现的视觉基线）

- **背景**（设置「外观 → 背景」）：
  - **内置背景**（默认「渐变光斑」，也可选「自选图片」「歌单封面」）：整个窗口铺一张 WebGL 画布（`components/GlassBackdrop.tsx`），先画背景，再把标题栏、侧栏、歌曲区、日志栏（带 `data-glass` 的元素）画成真正折射背景的液态玻璃；这时这些面板的 CSS 底色、边框、阴影都去掉，窗口下面也不再铺系统材质。
  - **系统材质**：窗口透明，亚克力 / 云母透出桌面。网页读不到桌面，面板只能用 CSS 近似同一组参数。
  - 渐变光斑有四套配色（极光 / 海洋 / 日落 / 森林），深色主题是深底亮斑，浅色主题把底色与光斑都往白色推。
- **材质**：界面每一层（标题栏、侧栏、歌曲区、对话框、设置卡片、按钮）都是带色调的半透明玻璃，保持「能看见下一层」。色调浓度由 `--glass-strength`（设置里的「玻璃浓度」，默认 0.45）统一控制；色调颜色默认跟随主题，可在高级设置里自定义。
- **主题**：深色（默认）/ 浅色 / 跟随系统。颜色全部是 `styles/theme.css` 里的 CSS 变量（`--text-primary`、`--accent`、`--panel`、`--dialog-glass`、`--border` 等），深色底 `#0b0f17`、浅色底 `#f3f6fb`；强调色是粉红（深色 `#ff6b7d`，浅色 `#e0354a`）；状态色 `--success` / `--warning` / `--danger`。不要在组件里写死色值。
- **玻璃的 CSS 近似**（`glass/params.ts` 的 `glassCssVars` → `styles/glass.css`）：`--lg-rim` 是 `::after` + mask 画的 1 px 亮环，亮度按「高光角度」分布（迎光一侧最亮、对侧按「高光对侧强度」）；`--lg-edge` 是沿边缘向内的菲涅尔亮边与透镜感；`--lg-fringe` 是色散彩边（迎光偏红、背光偏蓝）；`--lg-shadow` 是阴影；`--lg-radius` / `--lg-corner-shape` 是圆角与超椭圆（CSS `corner-shape: superellipse(log2 n)`）。浅色主题下亮环的非高光部分改成很淡的深色描边，否则白边落在白玻璃上看不见。
- **按钮**：液态玻璃胶囊（圆角不超过高度一半），边缘有上面的亮环、菲涅尔与色散；主按钮是带强调色的玻璃。悬停亮环变亮，按下缩到 0.965 回弹。
- **景深与折射**：对话框打开时，下面的主界面（`.app-shell`）用 `filter` 虚化（程度由「背景雾度」决定，默认 30%）；再由 `#root` 上的 SVG 位移滤镜（`glass/underGlass.ts`）让对话框边缘折射它下面的界面并带色散。只有一个对话框时才折射；叠放时被盖住的对话框只虚化。对话框自身**不用** `backdrop-filter`：它会在折射之后再模糊一遍，把折射抹掉。
- **动效**：时长 120 / 200 / 320 / 460 ms，缓动 ease-out / ease-in / 弹簧，全部取自 `theme.css`；「减少动效」或系统减少动画时缩到 1 ms。
- **布局**：68 px 顶栏即自绘标题栏（最小化 / 最大化 / 关闭）；歌单侧栏展开 272 px / 收起 88 px（`Ctrl+B`）；歌曲表格固定行高 48 px；窗口最小 960×600。
- **控件形态**：胶囊按钮与分段控件（`Segmented`，选中块在分段之间滑动）、弹簧开关、带发光外圈的滑块、紧凑列表行；所有可交互控件有中文 `aria-label`。
- 设计灵感来自 Salt UI 的卡片 / 胶囊 / 紧凑 Item 与色彩层级，本项目没有引入它的运行时。

## 液态玻璃参数（设置「外观 → 高级设置」，`settings.json` 的 `liquidGlass`）

名字、范围与默认值沿用参考项目；模糊半径的默认值为了界面文字可读改成 24 px（参考是 1），模糊边缘默认关（否则 24 px 模糊下看不出折射）。
范围以 Rust 端 `settings/liquid_glass.rs` 的表为准，前端 `glass/params.ts` 的 `PARAM_GROUPS` 必须一致。

| 分组 | 参数（默认值） |
|---|---|
| 折射与色散 | 折射厚度 20 px（1–80）、背景距离 0.05（0–0.2）、折射系数 1.4（1–4）、色散增益 7（0–50） |
| 菲涅尔与高光 | 菲涅尔反射范围 30 / 硬度 20 / 强度 20（0–100）；高光范围 30 / 硬度 20（0–100）、强度 90（0–120）、聚拢度 50 / 对侧强度 80（0–100）、角度 −45°（−180–180） |
| 模糊、色调与阴影 | 模糊半径 24 px（1–200）、模糊边缘 关、色调 跟随主题（或 `#rrggbb`）、阴影扩散 25 px（2–100）、阴影强度 15（0–100）、阴影位置 (0, 10) px（各 −20–20，向下为正） |
| 形状 | 圆角 16 px（0–40）、超椭圆系数 5（2–7，2 是普通圆角） |

参考项目里只用来摆弄示范形状的宽 / 高 / 形状融合度 / 动画形变不保存；设置里的即时预览框（`components/GlassPreview.tsx`）画一个缩小的主界面和一块可拖动的玻璃，预览背景是渐变时叠一层细斜纹，方便看清折射。

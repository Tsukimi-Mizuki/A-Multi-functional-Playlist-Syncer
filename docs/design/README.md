# 界面设计参考

- 这里存放界面设计的参考稿（用户提供的截图 / 设计图），后续界面改动的视觉基准以此为准。
- 命名约定：`ui-<窗口或场景>.png`，例如 `ui-main.png`、`ui-editor.png`。
- 新增参考时在 AGENTS.md 的 §11「界面设计与视觉基线」登记文件名，并把关键约定（配色、圆角、间距、控件形态）用文字补在下方，便于无法查看图片的会话也能照着实现。
- 目前还没有用户提供的设计稿；在有设计稿之前，视觉基线就是下面描述的、已经实现在 `app/src/styles/` 里的液态玻璃风格。

## 关键约定（当前实现的视觉基线）

- **材质**：窗口透明，系统亚克力 / 云母铺在网页下面；界面每一层（标题栏、侧栏、歌曲区、对话框、设置卡片）都是带色调的半透明玻璃，保持「能看见下一层」。玻璃浓度由 `--glass-strength`（设置里的「玻璃浓度」，默认 0.45）统一控制。
- **主题**：深色（默认）/ 浅色 / 跟随系统。颜色全部是 `styles/theme.css` 里的 CSS 变量（`--text-primary`、`--accent`、`--panel`、`--dialog-glass`、`--border` 等），深色底 `#0b0f17`、浅色底 `#f3f6fb`；强调色是粉红（深色 `#ff6b7d`，浅色 `#e0354a`）；状态色 `--success` / `--warning` / `--danger`。不要在组件里写死色值。
- **层次细节**（`styles/glass.css`）：顶部柔光渐变、内侧 1 px 高光、外侧投影、`::after` + mask 画出的 1 px 边缘折光（左上 / 右下更亮）。
- **景深**：WebView2 透明窗口里 `backdrop-filter` 不可用，对话框打开时给下面的 `#root` 加 `filter` 虚化，叠放时被盖住的对话框也虚化。虚化与遮暗的程度由设置里的「背景雾度」（`--backdrop-haze`，0% 完全清晰、100% 完全看不清，默认 30%）控制。
- **动效**：时长 120 / 200 / 320 / 460 ms，缓动 ease-out / ease-in / 弹簧，全部取自 `theme.css`；「减少动效」或系统减少动画时缩到 1 ms。
- **布局**：68 px 顶栏即自绘标题栏（最小化 / 最大化 / 关闭）；歌单侧栏展开 272 px / 收起 88 px（`Ctrl+B`）；歌曲表格固定行高 48 px；窗口最小 960×600。
- **控件形态**：胶囊按钮与分段控件（`Segmented`，选中块在分段之间滑动）、弹簧开关、带发光外圈的滑块、紧凑列表行；所有可交互控件有中文 `aria-label`。
- 设计灵感来自 Salt UI 的卡片 / 胶囊 / 紧凑 Item 与色彩层级，本项目没有引入它的运行时。
